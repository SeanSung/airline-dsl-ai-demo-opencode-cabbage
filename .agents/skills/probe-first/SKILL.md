# Probe First（先探针，再路由）

## 何时使用

**主要触发（想法特征，非用户声明）**：用户给出一个想法、主题或文件，且没有进入任何明确流程。看想法的**内容特征**判定，不要等用户说出元认知语句：

| 想法状态 | 判定 | 动作 |
|---|---|---|
| 一句话、无结构、或「怎么做」含 2 个以上开放决策 | 需探针 | 使用本技能 |
| 有明确主题 + 明确动机，但方案全是开放决策（如「基于 X 做一个 Y，来源是 Z」） | 需探针 | 使用本技能（通常落在 HYBRID） |
| 已有清晰计划、决策点列表或 spec | 直接萃取 | 转 `grilling` |
| 用户明确要求「帮我想出新点子」 | 直接合成 | 转 `creative-ideation` |
| 已是 spec/tickets | 直接实现 | 转 `to-spec`/`to-tickets`/`implement` |

**次要触发（用户声明，已降为子集）**：用户说出「我不知道自己有没有方向」「我不确定脑子里有没有答案」「我的想法太模糊了」「你先帮我理理思路」等——此时同样使用本技能。

## 与 ask-matt 主干的关系

本技能是想法进入主干流程（`grill-with-docs` → `to-spec` → `to-tickets`）**之前的默认检查点**。它判定后把想法交给 `grilling`（萃取）或 `creative-ideation`（合成），两者再汇入主干。用户丢来一个想法而没说该走哪条路时，直接从这里开始。

## 核心模型

不诊断，只探测。认知状态不是「有答案/没答案」二分，而是连续谱；内省判断不可靠。改为：跑探针，观测行为信号，按信号路由。

三种状态：

- **EXTRACT（可萃取）**：答案存在，只是模糊或提取通道关闭。信号：能答出具体内容，或换问法后突然能说出。
- **GENERATE（需合成）**：答案不存在。信号：换问法重问仍空，全是套话。
- **HYBRID（碎片）**：部分存在。信号：答得出主题答不出为什么，或反之。

## 流程

按顺序执行，每步完成后检查信号再决定下一步。

### 第 1 步：探针（3 个问题）

连续提出以下 3 个问题，一次一个，等用户回答后再问下一个。**不要**提供示例答案、不要引导、不要给推荐答案——任何提示都会污染判定。

1. **主题**：「请用一句话说出你想做的主题。说不出完整句子，给一个词也行。」
2. **为什么**：「这个主题背后，让你兴奋或焦虑的具体点是什么？」
3. **最小版**：「如果只能做一个最小可验证的版本，它会是什么样？」

记录每个回答，归入三类：

- `答出` — 能说出具体名词、动词、例子
- `模糊` — 「就是……AI 相关的」「还没想好」
- `空` — 沉默或转移话题

### 第 2 步：判定

**不要问用户「你觉得你属于哪种」**——由你观测判定，判定后直接说明并执行。

| 观测 | 判定 | 路由 |
|---|---|---|
| ≥2 个问题答出，且至少一次回答带情绪（「啊对」「就是这样」） | EXTRACT | 转 grilling |
| 3 个全空或全模糊 | GENERATE | 转 creative-ideation |
| 恰 1 个答出，其余模糊 | HYBRID | 先合成后萃取 |

**强制舌尖检查**：判定为 GENERATE 前，必须对最模糊的问题换 2 个问法重问。例：「最小版」答不出，改问「你最想先摆脱什么麻烦？」「如果明天就要 demo，你最想展示什么？」。换问法后能说出 → 降级为 EXTRACT。不做此检查就路由会误判——舌尖状态（有答案但提取通道关闭）是最常见的误判来源。

### 第 3 步：路由

- **EXTRACT** → 调用 `grilling`（若在项目工作目录，用 `grill-with-docs`）：设计树、轮次、前沿、每个问题编号 + 推荐答案。告知用户「你的答案存在，我会通过提问帮你挖出来」。
- **GENERATE** → 调用 `creative-ideation` 的发散姿态；缺失时用同等发散流程：每轮产出 5–10 个候选，切换创意角度，不收敛。告知用户「现在没有现成答案，我们先把候选造出来」。
- **HYBRID** → 先跑一轮发散产出候选池，再对候选池逐项萃取（见第 4 步切换）。

### 第 4 步：切换（无缝合流）

切换是本技能的核心能力。用**行为信号**触发，不用用户声明：

| 当前路径 | 观测到 | 动作 |
|---|---|---|
| 萃取 | 用户连续 2 个问题答不出或全是套话 | 停止盘问，显式切换：「看来这里没有现成答案，我们转成生成候选。」→ 转发散 |
| 萃取 | 用户对推荐答案强烈反驳（「不是这个」「缺了什么」） | 萃取成功的信号——隐性标准被激活；继续盘问并追问反驳依据 |
| 合成 | 用户对某个候选有情绪反应（「对，就是这样」「这个有意思」） | 停止生成，显式切换：「你刚才的反应说明你知道自己要什么，我们转成收敛。」→ 转 grilling 收敛该候选 |
| 合成 | 用户对所有候选平淡或「随便」 | 继续生成，切换创意角度 |

切换时必须**用一句话告知用户路径变化**。切换点记下用户说过的最具体的一个词或短语，作为后续所有问题的锚点。

## 完成标准

全部满足才算完成：

- 用户能说出至少一个具体的方向句子（含名词与动词，非套话）
- 探针阶段「答出 + 情绪反应」或「生成后强反应」至少出现一次
- 对话没有以「随便」「你看着办」作为最终回答
- 若中途切换路径，切换点有显式声明

## 依赖与降级

- `grilling` / `grill-with-docs`：本仓库已安装；缺失时用等价逐层提问流程（编号问题 + 推荐答案 + 等待回答）。
- `creative-ideation`：本仓库已安装；缺失时用原生发散流程（每轮 5–10 个候选、换角度、不收敛）。
