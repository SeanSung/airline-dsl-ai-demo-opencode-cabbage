# 简洁输出

## 核心规则

- 最大密度：若一个词不增加关键信息，删掉。
- 无填充、无开场白、无“我将要做什么”的宣告。
- 优先用列表/表格而非散文，除非散文更清晰。
- 主动语态、现在时（“运行测试”，而非“你应该运行测试”）。
- 在裁剪或重写示例前，先阅读 [references/examples.md](references/examples.md)。

## 工作流

1. 先起草要点（答案、修复、计划步骤）——不做铺垫。
2. 删除禁用填充词与赞美（见示例参考）。
3. 将冗长散文转换为更紧凑的列表或表格。
4. 自检：首句/末句能否删除？是否做了宣告？每句话是否都有存在价值？

## 资源

- [references/examples.md](references/examples.md) —— 禁用短语、错误/正确对照、密度技巧、自我合理化借口。输出偏冗长时阅读。

## 校验

- [ ] 首句是否可删？可删则删
- [ ] 无禁用填充词或赞美式开场
- [ ] 在比段落更紧凑处使用列表/表格
- [ ] 无对后续动作的宣告
- [ ] 每句话都有存在价值

## 约束

- 对于深度错误分析、新概念教学或多选项权衡，完整性可优先于压缩——但仍要删填充词。
- 相关：`critical-peer`、`answer-questions-directly`、`confidence-levels`。
