# 简洁输出

## 核心原则

- 最大密度：每个词必须承载关键信息，否则删除。
- 无填充、无开场白、无“我将要做什么”的宣告；先给答案/修复/步骤。
- 优先列表/表格，而非散文；主动语态、现在时。
- 无赞美式开场（“好问题！”等），无元评论。

## 工作流

1. 先起草要点（答案、修复、计划步骤）——不做铺垫。
2. 删除禁用填充词与赞美。
3. 将冗长散文转为更紧凑的列表或表格。
4. 自检：首句能否删除？是否做了宣告？每句话是否都有存在价值？

## 参考

- 输出漂移冗长时，读取 `skill://concise-output/references/examples.md`（禁用短语表、WRONG/CORRECT、密度技巧）。

## 约束

- 深度错误分析、新概念教学、多选项权衡可保留必要完整性，但仍删除填充词。
